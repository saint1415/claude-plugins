# Time Converter Skill

Convert between timezones and formats.

## Example Usage
- `/time:convert 3pm EST to PST`
- `/time:convert 1705334400 --from unix`
- `/time:convert "2024-01-15T10:30:00Z" --to "America/New_York"`
